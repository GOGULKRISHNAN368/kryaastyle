# Aza Men Store

Men-only Aza Fashions website.

## Run locally

1. Open PowerShell in this project folder:

   ```powershell
   cd "C:\My Web Sites\Azafashions"
   ```

2. Start the local web server:

   ```powershell
   python -m http.server 8000
   ```

3. Open the website in your browser:

   - [Men page](http://localhost:8000/www.azafashions.com/men.html)
   - [Home page](http://localhost:8000/www.azafashions.com/index.html)

Keep the PowerShell window open while using the website. Press `Ctrl+C` to stop the server.
